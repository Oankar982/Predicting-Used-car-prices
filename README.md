# Predicting-Used-car-prices
## **<u>Overview</u>**

This project develops an end-to-end machine learning pipeline to predict used car prices based on vehicle specifications, usage, and other relevant attributes.

## **<u>Key Features</u>**

- Performed Exploratory Data Analysis (EDA) to understand feature distributions and relationships with car prices.
- Handled missing values and encoded categorical variables during data preprocessing.
- Performed feature engineering and analyzed feature importance to identify key factors affecting car prices.
- Built and evaluated Decision Tree Regressor and Random Forest Regressor models.
- Evaluated model performance using MAE, MSE, RMSE, and R² Score.
- Created informative visualizations using Matplotlib and Seaborn.
- Maintained clean, structured, and well-commented Python code.

## **<u>Models</u>**

- Decision Tree Regressor
- Random Forest Regressor

## **<u>Evaluation Metrics</u>**

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

## **<u>Results</u>**

The regression models were compared using multiple evaluation metrics to identify the most effective approach for predicting used car prices. Feature importance analysis provided insights into the vehicle attributes that have the greatest influence on pricing.
